# 🌿 Xylem
From root to result.

**Xylem** is an ETL library designed to move data with the same elegance and 
efficiency that plants move water.  Just as the xylem tissue provides the 
structural backbone and lifeblood of a tree, this project serves as the core 
pipeline for data infrastructure.

## Guidelines
* Written in F#.
* Modern F# and .NET features.
* Naming based around the xylem domain.
* Prefer correctness, relability and diagnostics over performance.
